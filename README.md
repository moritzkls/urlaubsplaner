# Urlaubsplaner ✈️

Jahres-Urlaubsplaner für Vanessa & Moritz – als Single-File-Webapp.

## Features
- Raster- und Jahrestabellen-Ansicht
- Urlaub & Gleittage pro Person mit getrennten Töpfen
- Vorjahres-Übertrag konfigurierbar
- Deutsche Feiertage (alle 16 Bundesländer)
- Wochenenden + Feiertage werden nicht vom Urlaubskontingent abgezogen
- Zusammenhängende Blöcke mit Beschriftungs-Funktion (z.B. "Italien")
- Auto-Save im LocalStorage
- iPhone-tauglich (Touch + PWA-Support)

## Nutzung
Einfach im Browser öffnen, oder via GitHub Pages live.

## Bedienung
- **Klick / Tippen** – Tag markieren
- **Ziehen / Wischen** – mehrere Tage markieren
- **Shift+Klick** (Desktop) – Bereich markieren
- **Rechtsklick / Lang drücken** – Block beschriften
